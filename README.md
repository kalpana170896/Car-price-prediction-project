# 🚗 CAR PRICE PREDICTION PROJECT

# 📌 Project Overview

This project predicts the **price of cars** using  
**Multiple Linear Regression (MLR)** Machine Learning Algorithm.

The user enters:

- Brand
- Year
- Engine Size
- Fuel Type
- Transmission
- Mileage
- Condition
- Model

Then the system predicts the **car price instantly**.
